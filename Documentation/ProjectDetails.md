1. urbanstay – Core Idea (Software View) MVP
urbanstay = A web app that connects two user types through listings and bookings
Host → creates property listings
Guest → searches listings and books stay
Everything in the MVP supports 3 core flows:
Browse/search places
View listing details
Book & manage stays

2. User Types (MVP)
   1️⃣ Guest 
Can browse/search listings
Can view details
Can book a place
2️⃣ Host (Property owner)
Can create & manage listings
Can accept or reject bookings
(Admin panel is NOT required in early MVP)
